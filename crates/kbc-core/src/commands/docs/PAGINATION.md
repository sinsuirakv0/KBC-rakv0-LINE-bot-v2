# 番号選択付き一覧の共通操作

2026-10-04。検索とOC送信先選択に共通化した実装。文面キーを変更しても入力の仕様は変更しない。

## 操作の契約

- 1ページは最大10件。表示中の番号1〜10をリプライして選択する。
- `次`・`前`で移動、`3p`のようなASCII数字と小文字pで指定ページへ移動する。
- ページ番号は1始まり。0p・範囲外・overflowは案内を返し、同じページへの移動は新しい一覧を送らない。
- `終了`で閉じる。既存の`取消`・`cancel`も維持する。
- 本人・同じトーク・送信成功した最新prompt・10分以内のSessionに限定する。通常会話の数字は扱わない。

`navigation.*`の文面キーはcommon.txtへまとめた。次・前・指定ページ・終了の説明と範囲外の案内を共有する。文面を編集するときは上記の入力語と番号の意味を維持する。文面から入力語を推測する処理は作らない。

## 関数と接続

| 関数・型 | 働き |
| --- | --- |
| pagination::PAGE_SIZE | 検索とOC送信先一覧が参照する10件の定数 |
| pagination::parse / Input | 選択・移動・終了・その他を判定し、移動先のoverflowを防ぐ |
| pagination::navigation | 現在ページから使える次・前とページ指定の共通案内を生成 |
| sessions::apply_inner | 検索の本人・prompt・pendingを検査し、送信成功後にページを確定 |
| commands::chat_page / session_reply | OCの送信先を10件ずつ表示し、共通入力を選択またはページ移動へ渡す |

OCのSession::Chatsはpage_sizeを保存する。旧8件一覧にはこの値がないため、旧「9=次」の入力を新「9=選択」と解釈せず、選び直す案内を返す。期限付きpromptの清掃は既存経路を使う。

setupの固定11項目・複数項目一括指定、URL審議の固定選択肢などはページのない設定操作として維持する。ID検索・URLルール・mute・履歴などの表示専用一覧へ、新しい番号リプライのSessionは追加していない。

既存Command SmokeとOC Smokeで検証した。23トークの一覧で9・10の選択、次・前・3p、同一ページ、範囲外、古いprompt、旧8件Sessionを確認した。build・型検査・Clippy・受信基盤と文面設定のSmokeも通過した。実OCでの送信・削除権限による表示差は別途観測する。
