BOT管理者専用テスト（o.testも利用可）
自由な表示名・複数人メンション: !help test-mention

スタンプ送信のテスト
!test sticker <セットID> <スタンプID>
!test sticker <セットID> <スタンプID> --version <数字> --option <STKOPT>
versionは省略時1、STKOPTは省略可能です。
!id stickerで対象スタンプのID・version・STKOPTを取得できます。
送信先は実行トーク。allow登録・--applyは不要です。
指定IDで送信を1回試し、API結果と送信メッセージIDを表示します。
LINE側が受理するかと、端末で表示されるかは実環境で確認します。
結果不明の自動再送はしません。

検証OCの登録・解除（複数指定可）
!test allow <sMID> <sMID> ...
!test allow list
!test allow remove <sMID> <sMID> ...
一度に16件、全体64件まで。再起動後も保持します。

メンション・管理操作のテスト
!test mention <pMID> -- 本文
!test delete <数字のメッセージID>
!test kick <pMID>
!test deputy on <pMID>
!test deputy off <pMID>
!test admin <移行先の副官pMID>
対象トーク変更: --target-chat <mMID>
mentionではpMIDの所属を照会するトークです。送信先は実行トークです。
sMIDは対象トークに指定できません。!id talkでmMIDを取得します。
現在の管理人指定: --from <pMID>（admin専用）
指定省略時は実行トークを照会。adminの移行元は対象OCのBot。
管理下の実行元・対象OCの両方をallowに登録します。
指定だけでは対象確認。--applyを付けると実行します。
本文指定の -- より前に --apply 等を置いてください。
例: !test mention <pMID> --target-chat <mMID> --apply -- 通知テスト
kickは再参加可能な強制退会。一般メンバーだけが対象。
adminは旧管理人を副官にし、指定した副官へ移行します。
対象側の権限で判定されます。結果不明は自動再実行しません。

リプライ表示のテスト
!test reply <メッセージID> <本文>
!test reply <メッセージID> --chat <返信元トークMID> <本文>
投稿先は実行トーク。--chatは返信元の照合用です。
replyにはallow登録・--applyは不要です。
本文は1,500 UTF-16単位まで。改行・連続空白を保持します。
本文を--chat等から始める場合は、本文の前に--を置きます。
返信元にリプライして!id replyでID、!id talkでトークMIDを取得できます。
別OCの表示可否・端末通知は実環境で確認してください。
