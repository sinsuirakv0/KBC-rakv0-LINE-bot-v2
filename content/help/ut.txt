ユニット検索

!ut 0
!ut ネコ
正式名称・別称を検索します。空白区切りは一つの名前内でAND検索。
通常はかな・大小文字・全角半角を正規化します。
!ut 検索語 -f
表記を変えず、正式な形態名だけを検索します。

!ut 0 origin
!ut 0 origin wide c
!ut 0 origin sprite s
!ut 0 origin gacha m
画像は icon / wide / sprite / gacha。
形態は f=第一、c=第二、s=第三、u=第四。既定f。
gachaは引数なし / m / z。

!ut 0 file
!ut 0 file c
利用できる関連ファイルから番号で選択します。

!ut 0 motion png f a 0
!ut 0 motion mp4 f w 0~~5 a 0~~5
!ut 0 motion gif c a
png / mp4 / gif、a=攻撃 w=歩行 i=待機 k=ノックバック。
pngはFrame番号（省略0）。動画は範囲を省略するか、開始~~終了・開始 終了。
--full で全体表示。動画は最大900Frame。

一覧へリプライ：1〜10=選択、終了=受付終了。
一覧は1ページ10件です。ページ移動は一覧へ「次」「前」、または「3p」（3ページへ）をリプライします。
切り替え後は、新しい一覧へ番号をリプライしてください。
検索した本人のみ・10分間。一覧は操作後・期限で削除。
別名：!unit
