敵ユニット検索

!tut 0
!tut わんこ
正式名称と別称を検索。空白区切りは一つの名前内でAND検索。
通常はかな・大小文字・全角半角を正規化します。
!tut 検索語 -f
表記を変えずに検索。-force も使用できます。

!tut 0 origin
敵アイコンを送信します。
!tut 0 file
利用できる関連ファイルから番号で選択します。

!tut 0 motion png a 0
!tut 0 motion mp4 w 0~~5 a 0~~5
!tut 0 motion gif a
png / mp4 / gif、a=攻撃 w=歩行 i=待機 k=ノックバック。
pngはFrame番号（省略0）。動画は範囲を省略するか、開始~~終了・開始 終了。
--full で全体表示。動画は最大900Frame。

一覧へリプライ：1〜8=選択、終了=受付終了。
一覧のリアクション：👍（いいね）=次、❤️（ハート）=前。
切り替え後は、新しい一覧へ番号をリプライしてください。
検索した本人のみ・10分間。一覧は操作後・期限で削除。
別名：!enemy
