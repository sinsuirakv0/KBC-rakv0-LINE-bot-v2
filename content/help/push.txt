通知はこのコマンドを実行したトークへ送信します。! と o. の両方に対応します。

!push <分後・日時> [内容]
例：!push 10 休憩終了
例：!push 10/9-12:00
日時はJST。10/9、2026/10/9、10/9 12:00、10/9(12:00)も使えます。
本文省略時は「指定した時間になりました。」。登録者をメンションします。

!push event <イベントID・名前> [-分数]
開催時刻と終了10分前に通知。-5で開催5分前にも通知します。
IDは現在のsale.jsonに未掲載でも登録できます。掲載後から通知します。
名前の候補が1件なら登録、複数なら一覧へのリプライで番号を選択します。
一覧は10件ずつ。次・前・3pで移動、終了で取消（10分間有効）。

!push event g [ガチャID・名前] [-分数]
省略で全ガチャの開催時刻と終了10分前に通知します。
名前の候補はR（レア）/E（イベント）/N（ノーマル）別のガチャIDです。

!push event all：全イベントの開催時刻のみ通知
!push event daily：毎日22時に翌日の24時間のイベント予定をスレッドへ通知
!push event <ID・名前・all・daily> del：該当設定を解除
!push event g [ID・名前] del：該当ガチャ（省略で全ガチャ）を解除
!push event del：イベント・ガチャ・翌日予定の設定をすべて解除
!push status [3p]：このトークの設定と予約件数

個別と全件の重複通知はまとめます。停止中の通知は送信しません。
アプリ・スケジュールの更新通知は !pushsetting を使います。
